# The Bio-Structure Hub Tutorials

Here we provide a range of step-by-step tutorials to use different methods in structure prediction, generation of structures, and further computational tools:

| Task      | Method /  Tutorial                       |
| ----------- | ------------------------------------ |
| Structure Prediction      | [AlphaFold 2](tutorial_AF2_bwVisu.md), [AlphaFold 3](tutorial_AF3_bwVisu.md) (including [templates](tutorial_use_templates.md)), [Boltz-2](tutorial_Boltz_bwVisu.md)  |
| Structure Design       | [Bindcraft](tutorial_Bindcraft_bwVisu.md), [Boltzgen](tutorial_Boltzgen_bwVisu.md), [RFDiffusion](tutorial_RFDiffusion_bwVisu.md) |
| Predict Interactions   | [PLM Interact](tutorial_PLM_bwVisu.md) |

In addition we offer [docking](tutorial_Docking_bwVisu.md), [molecular dynamics](tutorial_MD_bwVisu.md), and a [transition](tutorial_bwvisu2helix.md) tutorial from Jupyter Hub to command line access.



All of these tutorials are designed for [bwForCluster Helix](https://wiki.bwhpc.de/e/Helix), and specifically connected to the bwVisu Jupyter Hub. They can be adapted to work on other Jupyter Hubs, but might need modification. 

Feel free to [contact us](../contact.md) if you need any help with that!
